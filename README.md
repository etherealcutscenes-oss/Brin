ADDED CELESTIAL BODIES = 

Brin - Brin was first discovered on Kerbember 18th, 1832. Many people thought they had discovered a second kerbin. While they were partially right, they were wrong. Brin is an ocean world that contains frequent hurricanes, cirrus clouds, and green-yellow aurorae. So far, probes have detected microscopic plankton in its water. This world is incredibly unknown, and some rumors have spread about people hearing alien whale like sounds. Whatever is in that water, is not normal. Take extreme caution and also get some science.

Tyvern - Tyvern is a Mun sized icy moon that orbits Brin at a very close distance. It is currently unknown how this moon doesn't mess with the rings, and the icy moon seems to vibrate in a rhythmic pattern. Almost like something alive is signaling from the interior of a frozen wasteland...

Added scatterer support
PLACEHOLDER - Added Volumetric cloud support (currently using SPVE textures) 


I also added science. Now you can uncover the mysterious lore of these two celestial bodies.
